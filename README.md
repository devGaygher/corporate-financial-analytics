# Corporate Financial Analytics — Brazilian Steel Industry

**Data Portfolio / 03 | Rafael Gaygher**



## Visão Geral

Projeto de análise econômico-financeira de empresas brasileiras
do setor siderúrgico, utilizando dados públicos oficiais da
Comissão de Valores Mobiliários (CVM).

Será desenvolvido um painel de análise financeira como 
projeto de estudo a ser adicionado ao portifólio.

## Empresas Analisadas

- Gerdau S.A.
- Usiminas
- Companhia Siderúrgica Nacional (CSN)

## Período de Análise

2021 a 2025.

## Objetivos

- Extrair dados financeiros de fontes públicas oficiais.
- Desenvolver um pipeline ETL reproduzível.
- Realizar Data Profiling e validação de dados.
- Implementar reconciliações contábeis.
- Desenvolver um modelo dimensional.
- Armazenar e consultar dados utilizando MySQL.
- Construir indicadores financeiros.
- Desenvolver um dashboard executivo em Power BI.

## Stack Tecnológica

- Python

- Power BI
